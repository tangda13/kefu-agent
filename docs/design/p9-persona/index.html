买家画像重构：按“谁 · 怎么决策 · 看重什么”来建

两个问题：一是现在的画像名称把一次性的购买情境（为婚礼准备物品）或一条偏好（看重参数合规）当成人群，读起来像在描述某个人；二是新建画像的弹窗是一堆平铺的输入框，AI 生成框挤在顶上，看不出这些字段之间的关系。下面先说依据和新结构，再给改后的画面。示例数据是编的，只看版式。

依据：画像是在“细分”上叠加动机和关注点

常见的做法是先按人口、地理、心理、行为几个维度把顾客分群，再在每个群上补充目标、痛点和影响购买的因素，形成画像；电商场景里行为维度（购买频次、客单价、生命周期）最常用。“这类人怎么做购买决定”有一个被反复验证的分类：Sproles 与 Kendall 的消费者决策风格量表（CSI，1986），归纳出 8 种决策风格。

① 买家角色 · 谁在买决定问题的类型：个人消费者问尺码和退换，批发采购商问阶梯价和账期。
个人消费者礼品购买者小B店主批发采购商企业采购代购转售
对应：人口 / 职业维度
② 决策风格 · 怎么做决定决定对话的走向：价格敏感型一直压价，选择困难型反复比较，冲动型容易被一句话说动。
品质导向型品牌口碑型新奇尝鲜型享受逛买型价格敏感型冲动下单型选择困难型习惯忠诚型
对应：心理维度，取自 CSI 的 8 种决策风格
③ 客户价值层 · 和店铺的关系参数里要求的 4 类客户，决定有没有历史订单、该用什么沟通策略。
潜在意向客复购老客粉丝客沉睡客
对应：行为 / 生命周期维度

在这三项之上，再给每类人群补上关注点（最多 3 个：价格优惠、物流时效、退换政策……）和沟通方式（性格、进店情绪、国籍语言）。名称由前两项自动组成，例如“价格敏感型个人消费者”，一眼就是一类人。

一次性的购买情境不放进画像：“为婚礼准备”“节日送礼”“搬家”属于这一次接待发生了什么，应该写在场景剧本里（场景里已经有“隐藏信息”“买家目标”）。画像管“谁”，场景管“这次为什么来”，两者随机组合才有变化。

现在的名称问题改后（决策风格 + 买家角色 · 价值层 · 关注点）
看重参数合规的小型采购商一条偏好 + 身份，偏好和身份混在一起，规则也不统一品质导向型批发采购商 · 复购老客 · 看重：材质参数、质检资质
为婚礼准备物品的新娘一次性情境，不是人群；换到售后场景就讲不通谨慎犹豫型礼品购买者 · 潜在意向客 · 看重：物流时效、包装礼盒（“婚期前要到”交给场景剧本）
重视到货速度的独立站买家名称和“偏好”一栏重复冲动下单型个人消费者 · 粉丝客 · 看重：物流时效、新品
预算有限的在校大学生人口属性写进名称，和“价格敏感”是同一件事价格敏感型个人消费者 · 潜在意向客 · 看重：价格优惠、包邮
1. 名称没有统一规则40 个名称各写各的：有的是偏好，有的是情境，有的是人口属性。老师也学不会怎么起名。
改：画像改成结构化字段，名称由“决策风格 + 买家角色”自动生成（允许改）；内置 40 个按“6 种角色 × 8 种风格 × 4 个价值层”重新铺开，覆盖每种组合里有训练价值的部分。
要补：模板表加买家角色、决策风格、关注点、补充说明；买家 AI 的提示词按决策风格给出具体表现（价格敏感型会比价、压价）
2. 新建弹窗字段平铺，看不出关系8 个输入框一样重；“身份”“消费偏好”是自由文本，老师不知道该写多细；AI 生成框是个大文本框，按钮浮在右边。
改：分三组——这类买家是谁（角色、风格、价值层，用可点的选项）、看重什么（关注点最多选 3 个 + 一句补充）、怎么沟通（性格、情绪、国籍、语言一行四个）。AI 生成收成顶部一行输入框；右侧实时预览卡片和一个试抽出的买家。

新建任务 · 买家画像

3. 任务规则和画像库只是“半关联”现在后台的做法是：先从全部启用的画像里随便抽一个，再用任务里选的标签把它的字段盖掉。比如任务选了“沉睡客”，抽到的可能是“爱尝新品的社媒创作者”，客户类型被改成沉睡客，偏好却还是“喜欢新品试用”，前后矛盾。老师也看不到会从哪些画像里抽。
改：分成两步。第一步“从哪些人群里抽”：按客户价值层、买家角色、决策风格筛选画像（或直接勾选几个），只从符合的画像里抽，不再改它们的身份字段；第二步“每次随机变化的”只管沟通方式（国籍语言、性格、情绪），这些和身份不矛盾，可以随机组合。
4. 说明文字和实际行为不一致；场景和人群没对上页面写“不选就是完全随机”，实际上不选时用的是画像自己的默认值。另外选了“沉睡客户唤醒”场景，抽到的却可能是潜在意向客。
改：文案改成“不选就用画像的默认值”。场景加一项“适用客户价值层”（客户分层维护的 4 个场景已对应好，其他场景不限），新建任务选了场景后自动预选，老师可以改。底部实时显示符合的画像数量，并能试抽 3 个。
要补：任务规则加“人群范围”（价值层 / 角色 / 风格 / 指定画像）；场景加“适用客户价值层”；没有符合的画像时禁止下发
改后 · 新建任务里的买家画像先定人群范围（按场景预选），再定每次随机变化的沟通方式；底部是符合的画像数量和试抽结果
