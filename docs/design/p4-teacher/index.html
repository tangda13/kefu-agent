教师端版式：先告诉老师“现在该做什么”

管理端的“一张纸”适合设置页，但照搬到教师端就出了问题：教师端是每天要用的工作台，信息量大、要做判断。全部白底、细线、同样的灰字，什么都一样重，眼睛找不到落点；宽屏下表格被拉得很散；没数据的时候整页都是空图表。下面是诊断和改法，颜色、字体、外壳不变。示例里的数据按一个 45 人的班级编的，只用来看版式。

1. 没有主次：每样东西一样重数字、任务、图表、说明文字全是同一个分量，老师打开总览不知道先看哪。
改：总览第一屏只回答“现在要我处理什么”——待复核几份、几个学生卡住了、哪个任务快截止，每项能直接点过去。其他都往后放。
2. 宽屏下表格被拉散1920 宽的屏幕上，任务名在最左、操作在最右，中间一大片空白，眼睛要来回扫。
改：内容区限宽 1120，列少而紧；每行只有一个大数字（完成人数或成绩），其他都是灰色小字。
3. 页面“浮”着，没有边界纯白底上只有细线，内容和留白分不开，看起来像没排完。
改：教师端回到浅灰底 + 少量白色内容板（一页一到两块，不是卡片墙），每块有一个标题行，边界清楚。
4. 没数据时满屏空图表开学前几周全是“暂无”“—”和空柱子，占了大半屏。
改：没数据的模块收起成一句话；总览在刚开始时换成“开课三步”引导，一步做完打一个勾。
5. 颜色和标签在抢注意力蓝色开关、每行一个灰框标签、行内长句提示，比内容本身还显眼。
改：颜色只留给要老师注意的东西（红 = 低分、逾期；橙 = 快截止、多日没练）；开关和标签都降成灰色；说明文字放进空状态或悬停提示。
6. 操作太多太散每行“查看 / 编辑 / …”三个按钮，整列都是操作词。
改：整行可点开详情，行尾只留一个“…”。主操作每页只有一个黑按钮。

数据总览

改后 · 数据总览（有数据时）第一块是“需要你处理”的三件事，红/橙数字直接告诉哪里有问题；第二块是进行中的任务；最后才是成绩和能力
改后 · 数据总览（刚开课、还没有成绩时）不显示空图表，换成三步引导；已完成的步骤打勾

实训任务

改后 · 实训任务每行一个重点：完成人数进度条；截止时间换成“还剩 1 天”并按紧急程度上色；整行点开详情，行尾只有“…”

班级与学生

改后 · 班级与学生顶部一行班级概况；分组做成筛选标签；“7 天没练”“低于 60 分”直接标出来，老师一眼找到要找的学生

考核报表

改后 · 考核报表先四个核心数字（带较训前的变化），再“需要关注的学生”，然后分布和能力，排名表只留成绩和最弱项
