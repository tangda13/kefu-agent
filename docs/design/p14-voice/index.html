语音服务 · 买家音色池（第二版）

管理员来这块，想知道的是“德国买家听起来是什么声音、对不对”，不是“德语池里配了哪几个音色 ID”。这一版按买家国家排成卡片：国旗 + “德国买家 · 说德语”，女声、男声各一行，行首就是播放按钮，点一下就能听；卡片底部用一句话说正不正常、为什么。点“编辑”在右侧抽屉里勾选音色。只改这一块，阿里云、豆包、计费三块不动。

五、点“编辑” 德国买家

抽屉顶部还是国旗和“德国买家”。先选女声 / 男声，再勾音色，每个音色前面都是播放键。分三组：推荐（德国人设）、阿里云通用音色（会说德语）、豆包备用；豆包没有德语时直接说清阿里云出错会怎样。底部写已选几个。点“完成”回到页面，左栏“保存”生效。
