仪表盘升级：待办卡片 · 带小图的关键数字

现在数据总览的三个待办格和考核报表的四个关键数字，长得都是“灰色大 0 + 一行字”：格子很空，像表格的表头；数字是孤立的，看不出好坏、离目标还差多少；“要你处理的事”和“结果”也长成一个样。改成电商商家后台常见的做法：待办用带图标的卡片，关键数字配一个能一眼读懂的小图。数据是编的，只看版式；每页都画了“没数据”和“有数据”两屏，只截上半部分（下面的任务和图表不变）。

1. 待办格子像表头，不像待办三格连成一条，大灰 0 和标题挤在一起，“都处理完了”是唯一的信息。
改：三张独立卡片。左边图标块（复核 / 买家在等 / 快截止），右边“名称 → 大数字 + 单位 → 一句事实”，右上角“去复核 ›”。有待办时图标块和数字变红或橙、卡片描边也带一点颜色；没有待办时不再写“都处理完了”：图标块变灰并带一个绿色小勾（状态交给图标），第三行换成有用的背景——“本周已复核 3 份”“现在没人在接待”“进行中的 4 个任务都没设截止”。整张卡可点。
2. 关键数字是孤立的“93%”好不好、平均分离及格线多远、40/45 还差几个，都得自己算。
改：四张卡片各配一个小图——平均分配半圆仪表（满分 100，刻一道 60 分及格线），旁边“较训前 +9”绿色胶囊；及格率、优良率配环形图；参评学生配一条进度条。没数据时仪表和圆环只画灰色底圈，数字是浅灰“—”。
3. 需要关注的三格和上面不统一同样是大数字 + 标题，但没有图标，选中态也弱。
改：加原因图标（低于 60 分、退步、没有成绩），数字带单位“人”；选中的格子浅蓝底 + 底部蓝线，和页签一致。
4. 卡片之间留出间距现在关键数字是一整块板里用竖线隔开，和下面的板贴得很近。
改：每个数字是独立卡片，卡片之间 16px；和“需要关注”板之间也是 16px，不再挤在一起。
