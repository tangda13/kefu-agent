教师端：没数据时也画出仪表盘 · 指导输入框重做

两处改动。第一，数据总览、考核报表等页面在没有数据时，现在只剩一句灰字，老师看不出这一页将来是什么样、要等什么才会有数。改成“骨架照常画、数据位置留出占位、旁边写清还差什么”。第二，实时监控底部的指导输入区松散：快捷语占两行、输入框和发送按钮是分开的两样东西、学生暂离时照样能发却没有提示。示例数据按 2 人的开发班级编（和你现在看到的一致）。

1. 待办区没数据时只剩一句话“现在没有要你处理的事……”一行灰字，和有待办时完全是两张脸，老师每天打开总览，看不到自己熟悉的三个格子。
改：三个格子永远在。数字是 0 时变成浅灰色，下面写“都复核完了”“没人卡住”“没有快截止的任务”，配一个绿色小勾。
2. 成绩与能力没数据时只剩一句话老师不知道这里将来会有哪两张图，也不知道“还差什么”才会出现。
改：成绩分布和六项能力两张图照常画：坐标轴、分数段、六项名称都在，柱子和进度条用斜纹 / 虚线占位；中间一个小提示卡写“还没有评分 · 学生完成第一次接待后出现”，并给出“去看任务”。
3. 考核报表同样的问题四个数字写“暂无”，下面整块变成一句话，排名表不见了。
改：四个数字用浅灰色的“—”，下面写一行说明（“2 人里 0 人有成绩”）；“需要关注的学生”三栏照常显示，没有人的那栏写“没有”并配绿勾；成绩分布、六项能力、排名表都画骨架加提示卡。
3b. “需要关注的学生”只是三列名字三栏各自一小块，人数藏在标题里；只有名字和一句短语，看不出差在哪、多久没练；看到了也没法直接做什么。没人的栏空着一大块。
改：上面三格放原因和大数字（0 变浅灰 + “没有”），点格子筛选；下面一张统一名单：学生、原因标签、具体情况（几分、最弱哪项、退步多少、练过几次）、最近练习（7 天以上标橙）、操作（看记录；从没登录的给“重置密码”）。
4. 指导输入区松散四个快捷语占了两行；输入框只有一行，长一点的指导看不全；发送按钮离输入框有一段距离，禁用时是一块发白的蓝色；整块的上边线和右侧面板对不齐，右下角空出一块。
改：做成一个整体的输入框（像聊天软件）：顶部一行写“发给张三 · 只有学生能看到”，中间是多行输入，底部左边是“常用指导”按钮（点开是列表），右边是“Enter 发送”和发送按钮。快捷语收进菜单，不再平铺。
5. 学生暂离时照样能发，没有提示学生已经 14 小时没动，老师发指导学生也看不到，但界面上没说。
改：会话暂离时，输入框上方加一条橙色提示“张三已暂离 14 小时，指导会在他回来后看到”；会话已结束时输入框换成“这次接待已结束，去回放与评分复核”。
6. 这条规则要改进经验库之前写的是“没数据的模块收起成一句话”，这次你明确说不要这样。
改：经验库里换成“仪表盘和图表没数据时画骨架 + 占位 + 提示卡，不收成一句话；只有列表类（任务、公告）才用一句话 + 按钮的空状态”。

考核报表

改后 · 考核报表（还没有评分）页面结构和有数据时完全一样，只是数字是“—”、图表是占位；“需要关注”照常可用（谁还没有成绩）
改后 · 需要关注的学生（有数据时）整页画全（往下是成绩分布、六项能力、排名）。名单最多显示 5 人，按严重程度排序，其余点“查看全部”在抽屉里看，不管多少人这块高度不变。上面三格是原因，点一格就筛出这些学生；下面是统一的名单：原因、具体情况（分数和最弱项 / 退步多少 / 练没练过）、最近练习（多日没练标橙）、能直接去做的事
改后 · 点“查看全部 12 人”右侧抽屉放完整名单：可切换原因、搜索、导出这批人；报表页面本身不会被拉长
