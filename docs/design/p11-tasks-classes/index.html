实训任务 · 班级与学生：从“一张表”改成“一眼看出要管谁”

两页的问题相同：数据都有，但只是平铺成表格。任务页三个页签把任务拆散，空页签只剩一句话；任务行里“0/2 人完成、未评分、不设截止”一样重。班级页的统计条和按钮挤在一个面板里，班级切换放在顶部页签，“需要关注”藏在筛选标签里。示例数据是编的（一个 45 人的班），只看版式。

1. 三个页签把任务拆散，空页签只有一句话老师要来回切才知道有没有快截止的、有没有预约好的；“未开始 0”“已结束 0”点进去是空的。
改：取消顶部页签。工具栏里放状态分段（全部 / 进行中 / 未开始 / 已结束，带数量）和业务环节筛选。“全部”时按状态分组：进行中在前，未开始其次，已结束收成一行“已结束 3 个 · 展开”；没有任务的分组不显示。
2. 任务行每一列一样重，看不出哪个要管完成情况、平均分、截止平铺成表格列，进度条很淡，“未评分”“不设截止”和真实数字一样显眼。
改：任务做成卡片，三列一排。头部是业务环节和状态点；中间三格只放做判断的数：完成人数 + 进度条、平均分（低于达标线标红）、剩余时间（2 天内标橙）。没有数据的格子用浅灰“—”，口径进问号。底部两个去处：“看跟踪”“看成绩”。
3. 未开始、已结束的任务没有自己的样子未开始的任务也显示“0/2 人完成”，已结束的和进行中的长得一样。
改：未开始卡片用浅灰底，中间换成“10 月 16 日 08:00 开放，还有 3 天”；已结束卡片变淡，保留最终完成率和平均分。
4. 班级页不该再放练习数据这一页是管名单的：建班、导入导出、分组、转班、重置密码、停用账号。练习情况在数据总览（需要关注）、考核报表（成绩与排名）、实训跟踪（实时）里都有，这里再放一遍是重复，还把名单操作挤到了下面。
改：去掉数字卡片和“需要关注”提示条；班级头部只留一句事实“23 名学生 · 3 个分组 · 2 个账号待改密”。
5. 班级放在顶部页签，班多了放不下超过 6 个班就变成下拉框；统计条和“导出 / 导入 / …”挤在一个面板里。
改：左侧一列班级清单（人数 + 待改密账号数角标 + 班主任 / 任课身份，底部“新建班级”）；右侧顶部是班名（可改名 / 删除）、班主任和任课老师、导出和导入。
6. 名单列围绕账号来排原来的“完成任务、平均分、最近练习”换成名单管理真正要看的信息。
改：学生（首字头像 + 姓名 + 学号）、分组、账号状态（正常 / 待改密 / 已停用，停用的整行变淡）、加入时间；行尾“…”里是编辑 / 转班、重置密码、停用、删除。筛选按分组和账号状态；勾选后出现批量操作条（分到组 / 移出分组）。
