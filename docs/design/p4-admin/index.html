管理端版式：从“卡片墙”到“一张纸”

现在的问题不在颜色和字号，而在结构：灰底上铺满带边框的白卡片，每块信息都装在一个盒子里，并排的盒子高度对不齐就留下空洞；标题、页签、统计条、卡片层层叠叠，看起来全是要填的表单。下面这版换一种组织方式，色彩和字体沿用已定的「墨白」，只改版式。

1. 一张纸，不要卡片墙内容区直接是白底，用留白和细分隔线分区，不再把每块内容装进带边框的盒子。只有弹窗、抽屉、提示这类浮在上面的东西才有边框和阴影。
2. 先结论，再明细每页第一屏回答“现在怎么样”：系统总览先说“运行正常，1 项待处理”，再列数据；性能验收用进度条和红线直接看出差多少，而不是一张五列表格。
3. 标题和页签合一页名和页签放在同一条页头里，省掉一整条横带；统计数字去掉方框，大号数字之间只用一条竖线分开。
4. 设置页用左右两栏左栏写这一节是什么、为什么要配，右栏放内容（Stripe、Vercel 的设置页都是这样）。读的人先懂再操作，不再是一屏表单。
5. 列表不是表格模型、服务这类条目少的列表用“图标 + 名称 + 状态 + 操作”的行，不要表头；只有真正需要横向对比的数据（成绩、用量明细）才用表格。
6. 对齐一条网格页面左右统一留 40px，所有分区共用同一组列宽，左右两栏顶部对齐、高度各自跟内容走，不会再出现你圈出来的空洞。
