三、数据总览 改 1–5

顶部四张卡用现在考核报表数字卡的样式（报表那排去掉后，只有这里用），四列和下面两栏对齐（每栏占两张卡宽）；平均分仪表盘的“60”标签留够位置，不再被裁。待办卡去掉后，“进行中的任务”上移到第二块，成绩分布和各项能力在首屏就能看到。侧栏“实训跟踪”上的红色数字是买家在等回复的学生数，现在就有，不改。

四、考核报表 改 6–9

整页按参数只剩三块：成绩分布、全班能力雷达、成绩排名，导出的 PDF 也是这三块。成绩分布上方是学校成绩分析常用的“一分两率”（平均分、及格率、优良率），虚线标出平均分落在哪一段。成绩排名表头的筛选替代原来的“需要关注的学生”：点“低于 60 分”只看这 4 个人；被标出来的学生名字后面写原因，红色数字就是原因所在的那一格。还没有成绩的学生排在最后。满意率跟着上面的班级和任务筛选走，只算任务里的聊天接待（报表本来就不算自由练习）。

五、复盘里的“本次接待” 学生端我的记录 · 教师端回放与评分

参照千牛、飞鸽的会话详情：仪表盘上是总数，每条记录的复盘里写这一次的数。买家评价 → 满意率；平均响应 → 平均响应时长；3 分钟回复率 → 工作台顶栏“更多”（替换没有意义的“12 小时响应率”）和我的记录“平均响应时长”卡的小字（替换“首次响应平均”）；对话轮次 → 累计对话的“共 N 轮”；询单结果 → 工作台顶栏的询单转化率、询单支付金额。接待时长和结束方式是这一次的过程信息。和总数用同一套算法（单轮等待封顶 10 分钟）。练习记录也显示（服务类总数含练习），邮件记录不显示（邮件不算接待）。下面只画复盘弹窗的右栏，其余照旧。

3 分钟回复率：买家每一轮消息（连发几条算一轮）3 分钟内得到回复的轮数 ÷ 轮数。买家最后一轮没等满 3 分钟会话就结束了，这一轮不算；等满 3 分钟还没回，算没达标。

六、四张数字卡怎么算

卡大数字小字小图问号里写
参训人数练过的人 / 名单人数—进度条至少接待过一次买家（含自由练习、邮件任务）的学生 / 班级名单里在用的学生
任务完成率百分比“已完成 96 / 135 人次”圆环每个学生的每个任务算一次；已完成的次数 / 应完成的次数（已下发的任务 × 名单里在用的学生）
平均分分数 / 100“41 人有成绩”半圆仪表，刻 60 分线和考核报表同一个算法：每个学生先算综合成绩（各任务成绩的平均），再求全班平均；自由练习不计入
对话总数次数“本周 126 次”近 7 天每天几次，今天标蓝全班学生“累计对话”加起来：学生回过话的聊天接待，含自由练习，不含邮件
